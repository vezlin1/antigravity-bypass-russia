# v2.6.4

## Совместимость с Antigravity App 2.29.0 и CLI 1.5.0

- **Поддержка актуальных версий**: обновлены фикстуры и подтверждена совместимость с официальным релизом Antigravity App 2.29.0 и Antigravity CLI 1.5.0 (Windows, Linux, macOS ARM64 и Intel x64).

## macOS: исправление создания резервных копий и путей пользователя

- **Исправлена ошибка создания временных файлов бэкапа**: устранена ошибка `Временный файл: No such file or directory (os error 2)` при патчинге `language_server` внутри `.app` на macOS. `prepared_file` теперь автоматически гарантирует рекурсивное создание родительской директории `.ag-backups` с правильными правами доступа (0700).
- **Безопасная смена прав (fchown)**: исключены ошибки EPERM при наследовании прав владельца директории, если процесс уже владеет ресурсом.
- **Исправлены пути домашней директории на macOS**: при вызове через `sudo` переменная `SUDO_USER` теперь корректно разрешается в `/Users/{user}` вместо `/home/{user}`.

## Сеть: увеличение таймаута проверок и fallback на прямые маршруты

- **Увеличен таймаут проверок (PROBE_BUDGET)**: таймаут на TLS/HTTP-проверку кандидата увеличен с 2500 мс до 4500 мс, устраняя ложные сбои `Нет однозначного проверенного маршрута для cloudcode-pa.googleapis.com` на интернет-соединениях с пингом более 500–700 мс.
- **Прямой TLS-fallback для Google сервисов**: если прокси-ноды недоступны или SmartDNS вернул прямые адреса Google, утилита тестирует прямое TLS-подключение к эндпоинтам Google. Если соединение валидно и возвращает корректный HTTP-ответ, маршрут подтверждается и успешно фиксируется в hosts.

# v2.6.3

## Antigravity CLI: исправлен "Eligibility check failed"

В CLI 1.4.11 проверка аккаунта (eligibility/entitlement) выполняется отдельным
запросом к `aicode.googleapis.com` (`ManagementService/GetUserInfo`,
`entitlement.userTier`). Бинарный патч снимал только локальное ветвление, а
сам запрос уходил напрямую с регионального IP и получал отказ.

- `aicode.googleapis.com` добавлен в `NRPT_AGENT`: домен получает NRPT-правило,
  DNS-реле и пиннинг в hosts наряду с Cloud Code и Gemini API.
- Подтверждена подмена домена провайдером geohide.ru (прокси 159.194.200.33,
  193.233.112.x) — после включения обхода eligibility-запрос идёт через
  проверенный маршрут.
- Диагностика сети и дашборд учитывают новый хост автоматически; в проверку
  сети добавлена строка "Eligibility сервер (CLI)".

После обновления запустите включение обхода заново (пункт 1 меню или
`patch-files`), чтобы новый домен получил маршруты в hosts и NRPT.

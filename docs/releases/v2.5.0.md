# 2.5.0

Поддержка Linux из [PR #29](https://github.com/vezlin1/antigravity-bypass-russia/pull/29) объединена с исправлениями обнаружения CLI, авторизации и сетевых настроек.

## Linux

- Сборки x86_64 и ARM64, автоматический установщик, пакет `.deb` для x86_64 и PKGBUILD для Arch Linux.
- DNS-служба запускается через systemd. В окружениях без systemd, включая WSL, используется отдельный фоновый процесс.
- Agent, Gemini и поддомены AI Studio используют локальный DNS-релей. Остальные запросы передаются исходным DNS-серверам; сохраняются IPv6-ответы и DNS по TCP.
- Для systemd-resolved сохраняются DNS и домены интерфейса, обычная маршрутизация DNS и scope локальных IPv6-серверов. Поддерживается также обычный файл `/etc/resolv.conf`.
- Исходный DNS восстанавливается до остановки релея. Сторонние изменения настроек блокируют перезапись и откат; резервные копии сохраняются.
- Ошибки systemd и проверки открытых файлов больше не скрываются. Предупреждения `lsof` о посторонних GVFS/portal не блокируют патч; реальные ошибки и занятые файлы продолжают останавливать запись.
- Релей использует 127.0.0.55, не занимая адреса 127.0.0.53/54 системного резолвера. Проверяются ошибки привязки DNS-сокетов к интерфейсу.

## CLI и совместимость

- Исправлены обнаружение IDE-managed `agy` в `~/.gemini/bin`, авторизация x64 CLI и дополнительная проверка в режиме `agy --hub`. Патч и обновление прежнего патча выполняются с сохранением возможности точного отката.
- Добавлены дополнительные имена и каталоги CLI из PR #29, включая `antigravity-cli` и Scoop.
- Добавлен `aicode.googleapis.com` для проверки eligibility в CLI 1.4.11 и новее.
- Статус IDE отражает состояние поддерживаемого патча; неизвестные архивы требуют проверки.
- Проверены официальные App 2.28.1/2.28.2, IDE 2.6.0 и CLI 1.4.11/1.4.12. Актуальные версии и SHA-512 архивов CLI зафиксированы в проверках совместимости.
- Comss исключён из встроенных провайдеров. Явно заданные пользовательские DNS-провайдеры сохраняются при миграции настроек.

## Установка и сборка

- Исправлены адреса загрузки и установка единого macOS-лаунчера на Apple Silicon и Intel.
- Ускорена упаковка исходников macOS без изменения формата лаунчера. Доступен комплект для локальной сборки обеих архитектур на Mac.
- Linux x86_64 собирается с базой Ubuntu 22.04; ARM64 — перекрёстно с включённым OpenSSL. Пакет Debian указывает необходимые зависимости.
- Для файлов релиза формируется `SHA256SUMS.txt`.

## Условия работы и границы проверки

Linux-сборки рассчитаны на glibc 2.35+; x86_64 требует OpenSSL 3. Сторонняя управляемая символическая ссылка `/etc/resolv.conf` без доступного systemd-resolved не перезаписывается и требует отдельной настройки DNS. Без systemd автозапуск после перезагрузки не настраивается. Для macOS используется целевая минимальная версия 12.0.

Linux проверяется в Debian 12 под WSL 2, ARM64 — в QEMU; это не проверка на физическом ARM64-устройстве. Сетевые регрессии используют изолированные DNS/HTTPS-фикстуры. Интерактивный вход в Google и авторизованный запрос модели в эти проверки не входят.

# 2.5.0 — подготовка, не опубликовано

- Linux x86_64 и ARM64: сборки, установщик, пакет Debian и PKGBUILD для Arch.
- Запуск DNS-службы через systemd, либо отдельным процессом без systemd.
- DNS для Agent, Gemini и AI Studio с сохранением исходных серверов для остальных доменов; откат возвращает настройки, а сторонние изменения блокируют перезапись.
- Исправлены адреса загрузки и установка единого macOS-лаунчера.
- Сохранены исправления обнаружения agy, авторизации и `--hub`; добавлены пути из PR #29 и домен `aicode.googleapis.com` для CLI 1.4.11.
- Comss исключён из встроенных провайдеров; явно заданные пользовательские провайдеры сохраняются.
- Проверки совместимости обновлены до App 2.28.1, IDE 2.6.0 и CLI 1.4.11.
- Сохранён комплект локальной сборки macOS. Ошибки проверки открытых файлов останавливают изменение приложения.

Linux-сборки требуют glibc 2.35+ и OpenSSL 3. Для DNS используются systemd-resolved или обычный `/etc/resolv.conf`; сторонние управляемые символические ссылки не перезаписываются. Без systemd служба не сохраняется после перезагрузки. ARM64 в CI собирается перекрёстно; нативная проверка на ARM64 остаётся отдельным этапом.

Изменения PR #29: [animesao](https://github.com/vezlin1/antigravity-bypass-russia/pull/29).
Тег и GitHub Release для этой версии не созданы.

## What's Changed

- Добавлена поддержка Linux: x86_64 и ARM64, включая работу в WSL.
- Добавлены автоматический установщик, пакет .deb для Debian / Ubuntu и PKGBUILD для Arch Linux.
- Исправлены обнаружение Antigravity CLI и проверка авторизации при запуске через IDE.
- Обновлены проверки совместимости с Antigravity App 2.28.2 и CLI 1.4.12.
- Улучшена работа DNS для Gemini и AI Studio на Linux.
- Исправлены конфликты с systemd-resolved и восстановление исходных DNS-настроек при откате.
- Исправлены ошибки проверки открытых файлов на Linux. Предупреждения GVFS/portal больше не мешают применению патча.
- Comss удалён из встроенных DNS-провайдеров. Пользовательские DNS-настройки сохраняются.
- Исправлено отображение состояния патча Antigravity IDE.
- Улучшены установщик macOS и упаковка лаунчера.
- И много других исправлений и улучшений стабильности.

Спасибо @animesao за основу поддержки Linux в [PR #29](https://github.com/vezlin1/antigravity-bypass-russia/pull/29)!

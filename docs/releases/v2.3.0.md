## What's Changed

- Ускорена работа DNS
- Исправлены конфликты DNS-настроек на macOS.
- Обновлён список DNS-провайдеров: основным стал dns-ai.ru (DoH).
- Исправлен вход в Antigravity CLI на Apple Silicon (ARM64) — https://github.com/vezlin1/antigravity-bypass-russia/issues/12.
- Откат после обновления Antigravity больше не перезаписывает новую версию приложения.
- На macOS утилита подсказывает, какое разрешение включить, если система запретила изменять файлы приложения.
- Расширена диагностика сети в отчёте (`report`).
- И много других исправлений и улучшений стабильности.

**Full Changelog**: https://github.com/vezlin1/antigravity-bypass-russia/compare/v2.2.2...v2.3.0

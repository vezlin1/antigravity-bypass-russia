# Проверка кандидата 2.5.0 — 31 октября 2026

Исходники версии 2.5.0: ветка `codex/release-2.5.0-rc1`. Включены собственные обновления, исправления PR #29, безопасная обработка предупреждений FUSE и ускорение упаковки исходников macOS. Точный commit финальной сборки указан в pipeline ниже.

Windows: 8 тестов пропущены; Linux x64: 6; ARM64-патчер: 2. Это заранее отключённые отдельные сценарии, а не ошибки текущего запуска.

## Linux и откат

На release-бинарнике в изолированных пространствах PID, монтирования и сети проверены:

- Переключение настоящего системного резолвера для Agent, Gemini и поддоменов AI Studio; исходный DNS для обычных доменов, IPv6-ответов и TCP DNS.
- Повторная настройка, отсутствие systemd, точный и повторный откат hosts и DNS; сохранение работающего релея при сторонних изменениях DNS.
- Настоящий systemd-resolved 252 с отдельным D-Bus: DNS и домены интерфейса, пустой исходный список доменов, default route и исходный link-local IPv6 DNS.
- Отказ systemd не скрывается и не переключает DNS; unit проходит проверку синтаксиса.
- Ошибка запуска `lsof`, ненулевой код и неизвестные предупреждения блокируют запись. Разрешённые предупреждения посторонних GVFS/portal не скрывают настоящий процесс, открывший целевой файл.
- Официальные CLI 1.4.11 и 1.4.12: патч, нативный запуск `--version`, повторное применение и восстановление исходного SHA-256.

Рабочие DNS/VPN и установленные приложения хоста при этих проверках не менялись.

- Страница загрузки: App 2.28.2, IDE 2.6.0; манифесты всех четырёх платформ CLI: 1.4.12. Пины обновлены после проверки официальных архивов.
- App 2.28.2 Windows/Linux: одинаковый ASAR SHA-256 `046fa2ba9abe96bc915eb7ed12887c067396a8a12148842ab4f4e2cd05a68feb`; относительно проверенного App 2.28.1 изменён только `package.json`.
- Официальные CLI 1.4.11 и 1.4.12 для Windows x64, Linux x64, macOS ARM64/x64 проходят обнаружение, патч и откат. CLI 1.4.12 дополнительно проверен на нативных macOS-раннерах; проверки прежних CLI 1.2.10/1.2.14 сохранены.
- Пакет Debian: версия 2.5.0, amd64, зависимости, исполняемые права, алиас и побайтное совпадение вложенного движка с проверенной сборкой. Linux-дистрибутив проходит проверку точного состава и SHA-256.
- Скрипты установки проверены для Linux x64/ARM64 и macOS ARM64/x64. Проверены Windows/Bash-лаунчеры, исходный и нативный форматы macOS-лаунчера, комплект локальной сборки Mac и синтаксис Actions.
- Контрольные суммы используются при проверке пакета сборки. Границы macOS сохранены как в 2.4.0: Apple Silicon 11.0 и Intel 10.12. Проверяются load commands готовых Mach-O, а не только переменные окружения сборки.

## Финальная проверка

Pipeline релизной сборки проверяет все пять целей и собирает общий дистрибутив. Итоговый macOS-лаунчер включает отдельные нативные движки Apple Silicon и Intel.

В Windows-проверке установщика явно нормализованы пути Git Bash, включая случай, когда checkout и временные файлы расположены на разных дисках.

Интерактивный вход в Google, запрос модели с авторизацией и запуск GUI не выполнялись. Физическое Linux ARM64-устройство не использовалось.

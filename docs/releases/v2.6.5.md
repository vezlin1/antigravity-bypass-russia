# v2.6.5

## Совместимость с Antigravity CLI 1.5.3

- **Поддержка актуальной версии CLI 1.5.3**: обновлены тестовые манифесты, адреса загрузки и контрольные суммы SHA-512 для платформ Windows x64, Linux x64, macOS ARM64 и macOS Intel x64.
- **Подтверждена совместимость бинарного патчера**: проверено точное совпадение сигнатур обхода региональных ограничений (`CLI_GATE_X64_LONG_ORIG_REGEX` и `CLI_GATE_ARM64_ORIG_REGEX`) с новыми бинарными файлами Antigravity CLI 1.5.3.
- **Актуальность компонентов**: подтверждена полная совместимость с текущими версиями Antigravity App 2.29.0 и Antigravity IDE 2.6.0.

## Исправления стабильности и CI

- **Исправлена проверка занятости файлов (lsof) на Linux**: добавлена безопасная фильтрация предупреждений `lsof` для путей хранилища контейнеров (`/var/lib/containers/`, `/var/lib/docker/`, `/run/containers/`, `/run/docker/`), возникающих в runner-окружениях CI и на машинах с Podman/Docker без root-доступа.
- **Устойчивость загрузки фикстур CLI**: в `tests/verify_cli_profiles.py` добавлен механизм автоматических повторных попыток (retries) и увеличен таймаут загрузки официальных бинарников до 180 с для защиты от сетевых сбоев GitHub.
- **Синхронизация ссылок репозитория**: обновлены адреса загрузки релизов и скриптов на `animesao/antigravity-bypass-russia` в `install.sh`, `unlock_and_restore.sh`, `release.yml`, `PKGBUILD` и `README.md`.
- **Повышена стабильность тестов**: динамическое сопоставление имени репозитория в тестах инсталлятора, а также расширенный поиск исполняемого файла `bash` в Windows-окружении (включая Scoop и локальные установки Git).

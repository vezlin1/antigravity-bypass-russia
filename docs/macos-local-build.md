# macOS: запуск текущих исправлений

Скрипт `unlock_and_restore.sh` в локальном пакете от 5 октября 2026 года содержит
текущие исходники, включая исправления входа CLI и отката после обновления.
При первом запуске он собирает движок на вашем Mac. Поддерживаются Apple Silicon
и Intel. Это локальная сборка: версия в программе пока отображается как 2.2.2.

## Один раз установите инструменты для сборки

Откройте **Терминал** и выполните:

```bash
xcode-select --install
```

Дождитесь окончания установки в появившемся окне. Если инструменты уже
установлены, переходите дальше. [Инструкция Apple](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools/).

Установите Rust стандартным способом:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Выберите стандартную установку, затем откройте новое окно Терминала или выполните:

```bash
source "$HOME/.cargo/env"
cargo --version
```

[Инструкция Rust](https://doc.rust-lang.org/book/ch01-01-installation.html).
Для первого запуска нужен интернет: Cargo загрузит зависимости из Cargo.lock.

## Запуск

Скопируйте `unlock_and_restore.sh` на Mac. Если файл находится в «Загрузках»:

```bash
cd "$HOME/Downloads"
bash ./unlock_and_restore.sh
```

Запускайте **без sudo**. Движок запросит пароль администратора перед операциями,
которым нужны права. Символы пароля в Терминале не отображаются.

Первый запуск собирает программу; дождитесь меню. Последующие запуски используют
проверенную копию из `~/Library/Caches/antigravity-bypass-russia/source-builds/`.
Завершите обновление и закройте IDE, CLI и языковой сервер перед изменением файлов.

Для полного включения обхода можно выбрать соответствующий пункт меню или запустить:

```bash
bash ./unlock_and_restore.sh unlock
```

Для снятия обхода:

```bash
bash ./unlock_and_restore.sh rollback
```

Откат сохраняет установленную версию приложения. Если backup повреждён либо
сигнатура версии неизвестна, утилита сохранит файл и сообщит причину отказа.

## Проверка и диагностика

```bash
bash ./unlock_and_restore.sh status
bash ./unlock_and_restore.sh diagnostics
bash ./unlock_and_restore.sh report "$HOME/Desktop"
```

Последняя команда сохраняет диагностический JSON на Рабочем столе. Проверки
без входа в аккаунт не подтверждают доступ к модели; после применения отдельно
проверьте вход в CLI и обычную работу IDE.

Если Cargo не найден, повторите `source "$HOME/.cargo/env"`. Если Rust устарел,
выполните `rustup update stable` и повторите запуск. При ошибке компиляции
сохраните текст ошибки из Терминала; повторный запуск не применяет патч, пока
сборка не завершится успешно.

Скрипт и включённые исходники проверены локально на Windows. Нативное исполнение
новых проверок macOS, включая права и codesign, здесь ещё не подтверждено.

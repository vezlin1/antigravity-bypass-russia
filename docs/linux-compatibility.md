# Проверка Linux и актуальных версий

Объединение подготовлено локально в `codex/integrate-linux-pr29` как версия 2.5.0. Публикация и создание тега не выполнялись.

## Подтверждено 30 октября 2026

- Debian 12 x86_64 в WSL 2: нативная сборка, модульные тесты и socket-тесты.
- Настройка настоящего системного резолвера, Gemini и поддоменов AI Studio; обычные домены, IPv6-ответы и TCP DNS сохраняют исходные DNS-серверы.
- Повторная проверка выявила и устранила потерю обычного DNS при добавлении route-only доменов systemd-resolved: исходный default route сохраняется через `~.`, а откат возвращает первоначальный список доменов. Проверен полный цикл с пустым исходным списком доменов и стандартным stub-резолвером 127.0.0.53.
- Локальный IPv6 DNS (`fe80::…`) сохраняет scope интерфейса. Имя и индекс определяются через API ядра в текущем пространстве сети, без предположений о монтировании `/sys`.
- Запуск без systemd, повторная настройка, восстановление исходных `resolv.conf` и hosts, повторный откат.
- Сторонние изменения DNS блокируют откат; исходные настройки и работающий релей сохраняются.
- Настоящий systemd-resolved 252 и отдельный D-Bus внутри пространства имён: DNS и домены интерфейса применяются и восстанавливаются. Ошибка регистрации systemd unit не скрывается и не запускает незарегистрированный резервный процесс; сгенерированный unit проходит `systemd-analyze verify`.
- CLI 1.4.11 Linux: ошибка `lsof` блокирует запись; патч, нативный запуск `--version`, повторное применение и восстановление исходного SHA-256 проходят.
- Linux ARM64: сборка с `vendored-openssl`, запуск `--version`, 29 тестов патчера и 5 socket-тестов под QEMU AArch64. Это проверка в эмуляции, а не на физическом ARM64-устройстве.
- Официальные CLI 1.4.11 Windows x64, Linux x64, macOS ARM64 и macOS x64 сверены с SHA-512 из манифестов и проходят проверки обнаружения, патча и отката.
- App 2.28.1 Windows и Linux: одинаковый ASAR SHA-256 `cec1039f841be1976dfeef6a9fdb6e71c6981e6857c222430105e3b6979612af`. Внутри ASAR относительно 2.28.0 изменён только `package.json`; исполняемые JS-модули совпадают.

Сетевые сценарии используют локальные DNS/HTTPS-фикстуры в изолированном пространстве сети. Они проверяют настройку и откат, но не измеряют доступность Google из рабочей сети. Проверка App относится к архивам приложения; интерактивный вход и запрос модели с Google-аккаунтом не выполнялись. Для macOS выполнен `cargo check` обеих архитектур и проверки лаунчеров; физическое устройство Linux ARM64 и нативный запуск macOS не проверялись.

## Воспроизведение

```sh
cargo test --locked --bin antigravity-bypass-russia --test socket_tests
cargo build --locked
sudo python3 tests/verify_linux_runtime.py target/debug/antigravity-bypass-russia
```

Последняя команда требует `unshare`, `mount`, `iproute2`, `lsof` и OpenSSL. Она создаёт отдельные пространства PID, монтирования и сети: hosts, DNS, системные команды и служба тестируются без изменения рабочей сети WSL.

Опция `--cli-fixture /path/to/agy` дополнительно проверяет настоящий CLI актуальной зафиксированной версии (сейчас 1.4.12). Для прежнего CLI используйте `--cli-version 1.4.11`. Опции `--resolved-binary` и `--dbus-daemon` позволяют использовать распакованные официальные пакеты systemd-resolved и D-Bus внутри изоляции. Для их библиотек при необходимости задаётся `LD_LIBRARY_PATH`; пакеты не нужно устанавливать в рабочую систему.

Для сверки App:

```sh
python3 tests/verify_app_artifacts.py /path/to/resources/app.asar --previous /path/to/2.28.0/resources/app.asar
```

## Условия работы

Готовые Linux-сборки нацелены на glibc 2.35+ и OpenSSL 3. Поддерживаются systemd-resolved и обычный файл `/etc/resolv.conf`. Управляемая сторонней службой символическая ссылка без доступного systemd-resolved сохраняется без изменений; такая конфигурация требует отдельной настройки.

Linux использует 127.0.0.55, чтобы не занимать адреса systemd-resolved 127.0.0.53/54. Перед переключением DNS проверяется готовность релея. При откате исходный DNS восстанавливается до остановки процесса. Без systemd автоматический запуск после перезагрузки не настраивается.

## 💡 Что это такое и зачем нужно?

**Antigravity Bypass Russia** — это бесплатная и открытая утилита, которая раз и навсегда убирает ошибки доступности (**`User is ineligible`**, **`Location not supported`**) в **Google Antigravity**, **Gemini 2.0**, **Antigravity IDE** и расширениях для **VS Code / Cursor / Windsurf**.

Вам **больше не нужно**:
- ❌ Держать постоянно включённым медленный зарубежный VPN;
- ❌ Менять страну своего основного Google-аккаунта или регистрировать иностранные профили;
- ❌ Терпеть задержки и обрывы соединения в среде разработки.

## ⚡ Пошаговая инструкция (Быстрый старт)

### 🪟 Для пользователей Windows (10 / 11)

#### Вариант 1: Через готовый файл (Самый простой способ)
1. **Скачайте файл** [**`antigravity-bypass-russia.exe`**](https://github.com/vezlin1/antigravity-bypass-russia/releases/latest) из раздела релизов.
2. **Запустите** скачанный файл двойным кликом (при запросе системы подтвердите запуск от имени Администратора).
3. В появившемся меню **нажмите цифру `1`** (**`Полная разблокировка`**) и нажмите **Enter**.
4. Дождитесь надписи «Готово!», затем запустите Antigravity и войдите в свой Google-аккаунт! 🎉

#### Вариант 2: Запуск через скрипт PowerShell (Без скачивания .exe)
1. Скачайте репозиторий: нажмите зелёную кнопку **Code → [Download ZIP](https://github.com/vezlin1/antigravity-bypass-russia/archive/refs/heads/main.zip)** и распакуйте папку в любое удобное место.
2. Нажмите **Пуск**, начните вводить **PowerShell**, нажмите правой кнопкой мыши на **Windows PowerShell** и выберите **«Запуск от имени администратора»**.
3. В окне PowerShell перейдите в распакованную папку и выполните команду:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\scripts\unlock_and_restore.ps1
   ```
4. В открывшемся меню выберите пункт **`1`** и дождитесь завершения.

---

### 🍏 Для пользователей macOS (Apple Silicon M1–M4 & Intel)

1. **Скачайте проект** через кнопку **Code → [Download ZIP](https://github.com/vezlin1/antigravity-bypass-russia/archive/refs/heads/main.zip)** (или через команду в Терминале: `git clone https://github.com/vezlin1/antigravity-bypass-russia.git`).
2. Откройте приложение **Терминал** и перейдите в папку с проектом.
3. Запустите скрипт разблокировки:
   ```bash
   chmod +x scripts/unlock_and_restore.sh
   sudo ./scripts/unlock_and_restore.sh
   ```
4. В интерактивном меню выберите пункт **`1. Полная разблокировка`**. Скрипт сам настроит системный DNS в `/etc/resolver/`, снимет региональные проверки и переподпишет бинарные файлы.

## 🧠 Как это работает (простыми словами)

Инструмент работает точечно и полностью локально на вашем компьютере:

- 🌐 **Прямой интернет (100% скорости без задержек):**  
  Весь ваш обычный веб-трафик идёт напрямую через вашего провайдера на максимальной скорости.
- 🎯 **Умная селективная маршрутизация (SmartDNS):**  
  Только служебные запросы к серверам Google AI направляются через безопасный DNS-релей. Никакой лишний трафик через релей не проходит.
- 🔓 **Локальный патч региона:**  
  Снимает внутреннюю проверку страны в ядре Antigravity, позволяя использовать ваш текущий Google-аккаунт.

> [!NOTE]
> **Ваша конфиденциальность защищена:** Программа не сохраняет пароли, не читает ваш код и не передаёт личные данные третьим лицам.

## ✨ Что умеет утилита

- 🔓 **Полная разблокировка «под ключ» (Пункт 1 меню):** Включает все необходимые настройки в один клик.
- 🧩 **Автоматическое определение всех популярных редакторов:**
  - **Antigravity IDE** (автономная среда разработки от Google);
  - **Ядро Antigravity 2.0 (`language_server`)** для процессоров x64 и ARM64;
  - **Расширения Antigravity** для **Visual Studio Code**, **Cursor**, **Windsurf**, **VS Code Insiders** и **VSCodium**;
  - Консольная утилита **Antigravity CLI (`agy`)**.
- 🛠️ **Встроенная диагностика (Пункт 5):** Проверка прав, статуса системного DNS, задержки до серверов Google и целостности файлов.
- 🧹 **Очистка кэша V8 и DNS:** Автоматический сброс устаревшего кэша авторизации для мгновенного вступления изменений в силу.
- ↩️ **100% безопасный и чистый откат (Пункт 6).**

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>1. Нужен ли мне теперь постоянный VPN для работы в Antigravity?</b></summary>
<p>
<b>Нет, не нужен.</b> Вся прелесть утилиты в том, что после применения патча (пункт 1) Antigravity и Gemini работают напрямую через ваш обычный домашний или мобильный интернет.
</p>
</details>

<details>
<summary><b>2. Безопасно ли это для моего Google-аккаунта и компьютера?</b></summary>
<p>
<b>Абсолютно безопасно.</b> Проект полностью с открытым исходным кодом (Open Source). Программа не крадёт токены, не подменяет SSL-сертификаты и не собирает телеметрию. Исходный код доступен для аудита прямо в этом репозитории.
</p>
</details>

<details>
<summary><b>3. Замедлит ли утилита мой интернет или онлайн-игры?</b></summary>
<p>
<b>Ни на миллисекунду.</b> Утилита не является VPN-сервером и не «гонит» через себя гигабайты трафика. Она настраивает селективные правила исключительно для служебных доменов Google AI. Весь ваш обычный интернет работает на максимальной скорости вашего провайдера.
</p>
</details>

<details>
<summary><b>4. Что делать, если Google обновит Antigravity IDE?</b></summary>
<p>
Если после обновления редактора снова появится надпись о недоступности региона — просто запустите утилиту ещё раз и нажмите <b>1</b>.
</p>
</details>

<details>
<summary><b>5. Почему Windows SmartScreen или антивирус может предупреждать при запуске?</b></summary>
<p>
Это стандартное поведение Windows для новых открытых утилит без платной цифровой подписи от Microsoft. Программа полностью безопасна: нажмите <i>«Подробнее» → «Выполнить в любом случае»</i>. Вы также всегда можете собрать бинарник самостоятельно из исходного кода.
</p>
</details>

<details>
<summary><b>6. Что делать, если при авторизации бесконечная загрузка?</b></summary>
<p>
1. Запустите утилиту и выберите <b>Пункт 5 (Диагностика)</b>, чтобы убедиться, что связь с серверами Google доступна.<br>
2. Закройте Antigravity IDE.<br>
3. В утилите выполните <b>Пункт 1</b> заново (это очистит устаревший кэш V8 и обновит сетевой стек).
</p>
</details>

<details>
<summary><b>7. Как полностью удалить изменения и вернуть всё «как было»?</b></summary>
<p>
Просто запустите утилиту и выберите пункт <b><code>6. ПОЛНЫЙ ОТКАТ</code></b>. Программа вернёт оригинальные файлы из резервных копий <code>.bak</code>, очистит все сетевые записи и вернёт систему к заводскому состоянию.
</p>
</details>

## ↩️ Чистый откат в 1 клик

Если вы решите полностью удалить изменения:
1. Запустите `antigravity-bypass-russia.exe` (или скрипт).
2. Выберите пункт **`6. ПОЛНЫЙ ОТКАТ`**.
3. Программа автоматически:
   - 🔄 Восстановит оригинальные файлы ядра и интерфейса из резервных копий;
   - 🗑️ Удалит все записи в таблице NRPT (Windows) или `/etc/resolver/` (macOS);
   - 🧼 Сбросит кэш DNS и кэш сессий V8;
   - 🧹 Очистит созданные переменные окружения.

## 🛠️ Для разработчиков

Если вы хотите собрать бинарный файл самостоятельно из исходного кода:

### Требования:
- Установленный компилятор [Rust 1.75+](https://rustup.rs/)

### Сборка:
```bash
# Клонирование репозитория
git clone https://github.com/vezlin1/antigravity-bypass-russia.git
cd antigravity-bypass-russia

# Сборка релизной версии с максимальной оптимизацией (Fat LTO)
cargo build --release
```
Готовый исполняемый файл будет создан в папке: `target/release/`.
